What is on this page and what is not

Most of the analysis is ordinary: OLS with robust errors, bootstrap intervals, Benjamini–Hochberg. That code is not here. What is here is the scaffolding that let the study make claims a reviewer could check: how the Internet Archive became a ten-year time axis without crawling a live site, how one model read a decade of posts against a human-built codebook under a frozen instruction, how a change in the forum's page template was kept from masquerading as a trend, and how a set-aside file of cases was kept set aside by code rather than by promise. Excerpts are trimmed from the working scripts; paths, logging, and error handling are cut. Python 3.12+, NumPy, pandas, and the Anthropic SDK.

Starting points for a longitudinal LLM analysis

If you want to run the forum design on another public archive, this is the order the pieces go in. Each row is one step: the note says what the step does and why it is not optional; the code is the smallest working piece of it.

1 · Time axis

Build the sampling frame from the Internet Archive's CDX index, one year at a time, keeping metadata only. The year on every chart is the year the archive captured the page, never a scraped posting date. That is a limitation and it is stated as one, but it is also what let the study cover 2016–2026 without touching the live site. The query is domain-wide, collapsed on URL key so one capture per page per year survives, filtered to thread pages and HTTP 200. The identified user agent and the three-second sleep are not politeness theater; they are the terms of using a public archive for research.

2 · Who is speaking

Read role from the author-pane credential badge, never from the post body. A post that says "as a new grad" is text; a title line reading "BSN, RN" is a badge the forum rendered at capture. Only the badge is used, so the career-point stratifier in Finding 5 cannot be contaminated by what the person wrote. Forty-eight percent of posts carried a badge; the rest are "unclear" and stay in the denominators. The regex runs over a window of HTML before the post body on the old template and inside the comment wrapper on the new one.

 
# wayback_role_extract.py (excerpt)
CRED_TOKEN = re.compile(
    r"\b(RN|BSN|MSN|DNP|PhD|EdD|LPN|LVN|ADN|ASN|CNA|STNA|PCT|NP|APRN|CRNA|"
    r"CNS|CNM|FNP|AGNP|PMHNP|NNP|ACNP|CCRN|CEN|CPN|CMSRN|PCCN|Student|"
    r"Nursing Student|Pre-Nursing|Pre-Student|Educator|Nurse Manager|"
    r"Manager|Director|Professor|Instructor)\b")
STUDENT_WORDS = re.compile(
    r"\b(?:nursing\s+student|pre-?nursing|student\s+nurse|SN|GN|new\s+grad)\b", re.I)

def classify(creds: set[str], text_pane: str) -> str:
    c = {x.upper() for x in creds}
    if c & {"CRNA", "CNM", "CNS", "NP", "APRN", "FNP", "AGNP", "PMHNP", "NNP", "ACNP", "DNP"}:
        return "aprn"
    if c & {"EDUCATOR", "NURSE MANAGER", "MANAGER", "DIRECTOR", "PROFESSOR", "INSTRUCTOR"}:
        return "educator_mgmt"
    if c & {"RN", "BSN", "MSN", "ADN", "ASN", "CCRN", "CEN", "CPN", "CMSRN", "PCCN"}:
        return "rn"
    if c & {"LPN", "LVN"}:
        return "lpn_lvn"
    if c & {"CNA", "STNA", "PCT"}:
        return "cna_tech"
    if c & {"STUDENT", "NURSING STUDENT", "PRE-NURSING", "PRE-STUDENT"} \
            or STUDENT_WORDS.search(text_pane):
        return "student"
    if c & {"PHD", "EDD"}:
        return "other_licensed"
    return "unclear"

3 · Periods

Cut time by external history, not by the year a chatbot became famous. The contrast of interest is 2023–2026 against 2016–2019, with 2020–2022 as its own window. The warrant for the AI window is when hospital EHR vendors shipped machine-learning features and when national surveys began asking about them, not November 2022. Writing the periods down as a function makes the choice auditable and keeps the analyst from sliding the boundary after seeing a result.

def period_of(year: int) -> str:
    if year <= 2019: return "pre_ai"      # EHR-saturated, pre-pandemic
    if year <= 2021: return "pandemic"
    if year <= 2023: return "ai_start"    # hospital ML enters national measurement
    if year == 2024: return "ai_mid"      # ambient-scribe / operational-ML year
    return "recent"                       # 2025-2026; 2026 is thin coverage

4 · One model, one frozen instruction, a closed vocabulary

Score every post for meaning events and refuse any output that is not in the schema. An event is one of the 13 Rosso facets from the human codebook, marked as lived out (enacted), blocked (frustrated), or longed for (wished for), plus what the post blamed or credited (a named AI system, a system rollout, or an optimization practice such as ratios, metrics, dashboards, or charting load), and four yes/no flags for the post as a whole. The instruction file is hashed before the run and the hash is written into every scored record, so a later reader can prove no prompt edit happened mid-stream. The static instruction is cached server-side; only the post travels each call. The model's own words are never accepted as a category: a value outside the closed sets raises, and the post is logged as an error, not coerced.

 
# forum_texture_v1.py (excerpt; the instruction text is not published)
POLARITY = {"enacted", "frustrated", "wished_for"}
OBJECT   = {"named_ai", "implementation", "optimization", "none"}
STANCE   = {"dissatisfied", "mixed", "endorsed", "mention", "na"}
TASK     = {"taken", "added", "reconfigured", "unchanged", "na"}
EMOTION  = {"frustration", "moral_distress", "anxiety", "relief", "none"}
ATTRIB   = {"tool", "management", "staffing", "patient", "self", "unclear"}
OUTCOME_KEYS = ("quit_intent", "depressed", "anxious", "lack_of_control")

def prompt_sha() -> str:
    return hashlib.sha256(PROMPT_PATH.read_bytes()).hexdigest()

def validate(parsed: dict) -> dict:
    events = parsed.get("events")
    if not isinstance(events, list):
        raise ValueError("no events list")
    clean = []
    for ev in events:
        if ev.get("facet") not in FACETS:          raise ValueError("bad facet")
        if ev.get("polarity") not in POLARITY:     raise ValueError("bad polarity")
        sal = ev.get("salience")
        if not isinstance(sal, int) or not 0 <= sal <= 100:
            raise ValueError("bad salience")
        if ev.get("object") not in OBJECT:         raise ValueError("bad object")
        if ev.get("stance") not in STANCE:         raise ValueError("bad stance")
        if ev.get("task_fate") not in TASK:        raise ValueError("bad task_fate")
        if ev.get("emotion") not in EMOTION:       raise ValueError("bad emotion")
        if ev.get("attribution") not in ATTRIB:    raise ValueError("bad attribution")
        clean.append(ev)
    outcomes = {}
    for k in OUTCOME_KEYS:
        v = (parsed.get("outcomes") or {}).get(k, 0)
        if v not in (0, 1):
            raise ValueError("bad outcome")
        outcomes[k] = int(v)
    return {"events": clean, "outcomes": outcomes}

5 · Inference that respects threads and page templates

Treat the thread as the cluster, test with a permutation of period labels, and rerun everything per 1,000 words. Posts in one thread are not independent, so intervals come from resampling threads, and the p value comes from shuffling which threads sit in which period. Then the one thing that could manufacture a trend here: in 2019–2021 the forum changed software and posts got shorter, so events per post fell for reasons that have nothing to do with nurses. Every rate is therefore reported a second time as events per 1,000 words. Benjamini–Hochberg q is computed inside each family and contrast, beside the permutation p. One of those families is the 20-category screen named in the digital resource.

 
# MoW_phase2_period_contrasts_v1.py (excerpt)
class ThreadTable:
    """Per-thread numerators and denominators for a set of outcomes."""
    def contrast(self, a, b, scale):
        ma, mb = self.period == a, self.period == b
        ra, rb = self.rate(ma, scale), self.rate(mb, scale)
        diff = ra - rb
        ia, ib = np.flatnonzero(ma), np.flatnonzero(mb)
        boots = np.empty((B_BOOT, len(self.names)))          # B_BOOT = 2000
        for s in range(B_BOOT):                               # resample THREADS
            sa, sb = rng.choice(ia, len(ia)), rng.choice(ib, len(ib))
            boots[s] = (scale * self.num[:, sa].sum(1) / self.den[sa].sum()
                        - scale * self.num[:, sb].sum(1) / self.den[sb].sum())
        lo, hi = np.percentile(boots, [2.5, 97.5], axis=0)
        pool, na = np.concatenate([ia, ib]), len(ia)
        cnt = np.zeros(len(self.names))
        for _ in range(B_PERM):                               # B_PERM = 4000
            perm = rng.permutation(pool); pa, pb = perm[:na], perm[na:]
            d = (scale * self.num[:, pa].sum(1) / self.den[pa].sum()
                 - scale * self.num[:, pb].sum(1) / self.den[pb].sum())
            cnt += np.abs(d) >= np.abs(diff) - 1e-12
        return ra, rb, diff, lo, hi, (cnt + 1) / (B_PERM + 1)

# Family A: events per 100 posts. Family S: the same events per 1,000 words.
ttA = make_A("posts")    # denom = 1 per post
ttS = make_A("words")    # denom = n_words per post; the template-change check

def bh(p):   # Benjamini–Hochberg q within each family and contrast
    n = len(p); order = np.argsort(p)
    ranked = p[order] * n / (np.arange(n) + 1)
    q = np.minimum.accumulate(ranked[::-1])[::-1]
    out = np.empty(n); out[order] = np.minimum(q, 1.0); return out

6 · The pass mark comes from the humans

Compute the human-pair ceiling with the same rollup and the same agreement statistic the model will face, with a bootstrap interval. Proportion of specific agreement on "present" is the right statistic for sparse binary codes; kappa punishes rare facets. The ceiling is computed per dimension, not once overall, which is how the study found that agency (.93) and communion (.48) are different measurement problems. The lower bound of the interval became the model's bar, written down before any model was scored.

 
# mow_human_psa_benchmarks.py (excerpt)
from mow_train_common import FACETS, or_2x2, or_pathways, psa
DIMS = ("Agency", "Communion", "Self", "Others")
B, SEED = 10_000, 20260916

def case_dims(df, coder_col):
    rows = {}
    for sid, g in df.groupby("StudyID"):
        facets = dict(zip(g["facet"], g[coder_col].astype(int)))
        rows[sid] = or_2x2(or_pathways(facets))   # facet -> pathway -> 2x2, by OR
    return pd.DataFrame.from_dict(rows, orient="index").sort_index()

def boot_ci(a, b, rng):
    stats = []
    for _ in range(B):
        idx = rng.integers(0, len(a), len(a))     # resample cases
        v, *_ = psa(a[idx], b[idx])
        if not np.isnan(v):
            stats.append(v)
    return float(np.percentile(stats, 2.5)), float(np.percentile(stats, 97.5))

mjm = case_dims(linked, "MJM")    # first author
dd  = case_dims(linked, "DD")     # second coder
for d in DIMS:
    a, b = mjm[d].to_numpy(), dd[d].to_numpy()
    v, tp, fp, fn = psa(a, b)
    lo, hi = boot_ci(a, b, rng)

7 · A seeded partition with a hash on the ID list

When a holdout has to be split, draw once with a recorded seed and stratify on what makes cases hard. The analysis file stores the IDs. What is published is the SHA-256 of that ID list. The tracked file carries IDs and the subsplit label only; the stratum columns that would reveal label structure go to a git-ignored companion. The assertions are guards, not a loop that re-seeds until the draw looks good; the record states that the first seed satisfied both constraints.

 
# MoW_test_partition_v1.py (excerpt)
SEED, N_A, PA_B_MIN = 20260926, 65, 49
rng = np.random.default_rng(SEED)
t["stratum"] = (t["has_both_present"].astype(int).astype(str) + "|"
                + t["occupation_block"].astype(str) + "|"
                + t["in_tier2_gold"].astype(int).astype(str))
frac = N_A / len(t)
t["subsplit"] = "test-B"
alloc, rem = {}, []
for s, g in t.groupby("stratum"):                 # largest-remainder allocation
    raw = len(g) * frac
    alloc[s] = int(np.floor(raw))
    rem.append((raw - alloc[s], s))
for _, s in sorted(rem, reverse=True)[: N_A - sum(alloc.values())]:
    alloc[s] += 1
for s, g in t.groupby("stratum"):
    pick = rng.choice(g.index.to_numpy(), size=alloc[s], replace=False)
    t.loc[pick, "subsplit"] = "test-A"

nA = int((t["subsplit"] == "test-A").sum())
paB = int(t.loc[t["subsplit"] == "test-B", "has_both_present"].sum())
assert nA == N_A          # guards on the single recorded draw, not a re-seed loop
assert paB >= PA_B_MIN

full = t[["StudyID", "split", "subsplit", "has_both_present",
          "occupation_block", "in_tier2_gold"]]
full.to_csv(OUT_FULL, index=False)                              # git-ignored
full[["StudyID", "split", "subsplit"]].to_csv(OUT, index=False) # tracked IDs
ids_b = ",".join(sorted(full.loc[full.subsplit == "test-B", "StudyID"]))

8 · The scorer refuses to mix prompts or splits

Every folder of scored cases records the hash of the instruction it was scored under; a resume under a different hash is a hard error. Split membership is checked per case, and holdout IDs are refused unless a dated decision record's own hash matches a constant compiled into the runner. This is the difference between "we did not look" and "the code would not let us look." It also means a crashed run can be resumed without re-buying scored cases, because the cache is verifiable.

 
# mow_dev_runner.py (excerpt)
def guard_case_dir(case_dir: Path, prompt_sha: str) -> None:
    """Refuse resuming a case dir scored under a different frozen prompt."""
    sha_fp = case_dir / "PROMPT_SHA.txt"
    existing = [p for p in case_dir.glob("*.json")]
    if sha_fp.exists():
        recorded = sha_fp.read_text(encoding="utf-8").strip()
        if recorded != prompt_sha:
            raise RuntimeError(
                f"Case cache {case_dir} was scored under freeze SHA "
                f"{recorded[:12]}… but the loaded freeze is {prompt_sha[:12]}…. "
                "Refusing to mix outputs from two prompts in one selection. "
                "Use a fresh --outdir (or delete the stale case dir).")
    elif existing:
        raise RuntimeError(
            f"Case cache {case_dir} contains {len(existing)} case JSON(s) but "
            "no PROMPT_SHA.txt, so their prompt provenance is unverifiable. "
            "Use a fresh --outdir; do not resume unverifiable caches.")
    else:
        sha_fp.write_text(prompt_sha + "\n", encoding="utf-8")

If you are starting tomorrow

  1. Pick the public archive and write down, before you query it, what the time variable will mean (capture date, posting date, or something else) and what you will not be able to say because of that.
  2. Get a human codebook that already has a measured ceiling. Scoring posts against a scheme two humans could not agree on gives you a model that agrees with no one.
  3. Freeze the instruction, hash it, and write the hash into every output record. Treat any later edit as a new instrument with a new name.
  4. Define a closed output vocabulary and reject anything outside it. Do not let the model invent a category.
  5. Cut time by documented external events and write the boundaries as a function before the first result.
  6. Cluster on the unit that actually repeats (thread, author, site), and rerun every rate under a second denominator that would expose a format change.
  7. Report q beside p, name the number of tests, and label the whole thing descriptive if no human has checked the model on that text. Draw the human check sample at the start, even if it waits.
